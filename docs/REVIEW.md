# 全体レビュー・修正記録（2026-10-05）

対象は全アプリケーションコード、既存テスト、SQL マイグレーション、設定、依存定義、設計資料。
本番データ、Supabase 管理設定、実トラフィック、バックアップ状態は参照していない。
以下はコードから確認した問題と対処であり、未知の欠陥が存在しないことの保証ではない。

優先度は P0＝機密性に直結、P1＝データ消失・誤精算・主要機能不全、P2＝性能・保守性・操作性、P3＝軽微な改善。
「修正済み」はこの作業ツリー内を指す。本番には適用していない。

## 検証

- 型検査・読み取り専用書式検査・lint を bun で実行。
- 精算の保存則・整数性・入力順不変性、認可・RLS・ロールバック、1,000件超の取得を追加検証。
- `bun run build` は仮の公開 Supabase 設定で成功。本番サービスへの接続検証ではない。
- テストの Auth identity はスタブ。実データ・本番 DB への変更はなし。
